# Adding event photos from Google Drive

If the Drive folder can't be downloaded automatically, copy photos here and update paths in `content.json`.

Suggested filenames (match to events):

| File | Use for |
|------|---------|
| `celebration-2026.jpg` | 2026 symposium |
| `celebration-2025-boateng.jpg` | 2025 Dr. Boateng Evans event |
| `art-night-peabody.png` | Art Night (already added) |
| `comics-from-the-heart.jpg` | Comics from the Heart |
| `holiday-party.jpg` | Holiday study break |
| `pitt-watch-party.jpg` | The Pitt watch party |
| `meet-greet.jpg` | Meet & Greet |
| `study-break.jpg` | HuMed study breaks |

Then tell Cursor to update `content.json` image paths.
